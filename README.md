Adventure Quest: The Lost Princess

A narrative-driven, interactive 2D adventure game built with Python and Tkinter. Embark on a journey through mysterious forests, gloomy swamps, and ancient castles to rescue a princess or forge your own destiny.
 Features

    Dynamic Storytelling: Random events and multiple endings based on your choices.

    Multiple Protagonists: Play as the King, the Knight, or the kidnapped Princess herself.

    Quest System: Interact with unique NPCs (Witch, Guard, Merchant) to solve puzzles and earn rewards.

    Inventory Management: Collect items like magic talismans, silver coins, and dungeon keys to unlock new paths.

    Visual Interface: A custom UI with dynamic background changes and character avatars.

 Tech Stack

    Language: Python 3.x

    Library: Tkinter (GUI)

    Graphics: Pillow (PIL) for image processing

How to Play

    Choose your character: Each hero has a different starting perspective.

    Explore locations: Navigate between the Forest, Castle, Swamp, and Magic Ruins.

    Complete Quests: Talk to NPCs to gather information or items.

    Make Decisions: Your choices determine whether you rescue the princess through diplomacy, force, or stealth.

Installation & Setup

Ensure you have Python installed. You will also need the Pillow library to handle game graphics.

    Clone the repository:
    Bash

    git clone https://github.com/your-username/adventure-quest.git
    cd adventure-quest

    Install dependencies:
    Bash

    pip install Pillow

    Run the game:
    Bash

    python main.py

 Project Structure

    main.py — The entry point of the game.

    data.py — Game logic constants, NPC data, and paths.

    ui.py — GUI implementation using Tkinter.

    images/ — Directory containing backgrounds and character sprites.
